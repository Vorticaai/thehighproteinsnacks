# 🥇 The High Protein Snacks — Comparison & Ranking Directory

**https://www.thehighproteinsnacks.com**

The High Protein Snacks project is a searchable, ranked directory of the best high-protein snacks available online.  
It helps users compare snacks by:

- Protein per serving  
- Sugar and calories  
- Price per serving  
- Keto / vegan / halal / gluten-free filters  
- Brand, category, and value score  

The site is built with **Next.js App Router**, **TypeScript**, and a fully **CSV-driven dataset**, making it extremely fast and SEO-friendly.

This repository includes the core codebase powering the website, along with the product schema, utility scripts, and frontend components.
